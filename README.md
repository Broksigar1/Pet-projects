# Pet-projects
Репозиторий с пет-проектами\
Проекты
1) Simple API\
Задача - разработать REST API для получения данных из БД. Сделать одностраничный сайт (UI) для работы с API.\
\
Что именно сделать:
1 - Разработать схему БД мебельного склада. Таблицы - Products (описывает товары на складе), Categories (категория товара: стулья, столы, кровати и т.п.)\
2 - Разработать REST API. Сделать к нему документацию в Swagger. Методы API - получение всех товаров с их категориями, добавление/удаление/изменение товаров, добавление/удаление/изменение категории\
3 - Разработать UI для обращения к REST API\
4 - Покрыть API unit-тестами\
5 - Выложить UI в интернет\
\
Что использовать - ASP.NET Core (C#), MS SQL Server, NUnit, Blazor\
