FlyWay\
Сервис, который позволяет пользователю искать авиарейсы из одного города в другой\

Цель проекта - научиться настраивать JWT аутентификацию, работать с ASP.NET MVC, EntityFramework, RabbitMQ, SMTP

Что сервис должен уметь?
1) Позволяет пользователю зарегестрировать аккаунт/войти в аккаунт, сменить пароль
2) Искать авиарейсы. Пользовтель вводит:\
— Аэропорт вылета (обязательно)
— Аэропорт прилета (обязательно)
— Дата вылета или дата прилета (можно ввести либо оба, либо одно из двух)
Ограничения: показываются только прямые рейсы
3) Должна быть возможность подписаться на изменение списка авиарейсов, которые пользователь нашел. При изменении пользователю на почту должен приходить Email с информацией об изменении
4) Получать список авиарейсов от строннего сервиса и сохранять их в базе

Как такое написать?
1) Написать сервис авторизации, использующий JWT
2) Написать сервис с REST API на ASP.NET MVC, который принимает новые авиарейсы/изменяет существующие авиарейсы и с помощью RabbitMQ пересылает сообщений сервису, который кладет авиарейсы в БД
Данный сервис имитирует собой сторонний сервис, который отправляет нашему приложению FlyWay авиарейсы
3) Написать сервис, который через RabbitMQ получает сообщения об авиарейсах и кладет их в БД. Если есть пользователи, которые подписаны на события об изменении авиарейсов, то этот сервис кладет
в RabbitMq сообщения с информацией о том, какому пользователю и что именно нужно отправить на Email
4) Сервис отправки Email по SMTP. Читает сообщения из RabbitMq и отправляет пользователям сообщения по SMTP на Email
5) Написать REST API, которое позволяет пользователю искать авиарейсы
